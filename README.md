# Portfolio Website - Riski Yana Ramadhan

🚀 A clean, dark-themed personal portfolio built with **React + Vite**.  
It highlights my profile as a **Backend Developer**, technical skills, project experience, and contact channels in one smooth single-page experience.

---

## ✨ Highlights

- 🌐 **Bilingual content** (Indonesian / English) with instant language toggle
- 🧭 **Smooth section navigation** (`Home`, `About`, `Experience`, `Contact`)
- 📱 **Responsive layout** for desktop and mobile
- 🧠 **Skills showcase** with modern icon-based tech stack cards
- 💼 **Project/experience cards** with external links and detailed summaries
- 📬 **Contact section** with email, phone, location, and social profiles

---

## 🛠 Tech Stack

- **Core:** [React](https://react.dev/), [Vite](https://vitejs.dev/)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/), `tailwind-scrollbar`
- **Icons:** [Lucide React](https://lucide.dev/), [React Icons](https://react-icons.github.io/react-icons/)
- **Code quality:** ESLint (React + Hooks)
- **Props validation:** PropTypes

> Note: `react-router-dom` is listed in dependencies but is not used yet (current navigation is section-anchor based).
